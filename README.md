# FFmpeg 静止画面剪切器

一个面向 Windows 桌面的半自动视频剪辑工具：自动检测 MP4 中的静止画面区间，用户逐段预览确认，选择一个或多个区间删除，并导出新的 MP4。

## MVP 目标

1. 打开本地 MP4。
2. 使用 FFmpeg `freezedetect` 检测静止区间。
3. 以列表形式展示全部静止区间。
4. 点击候选区间后，播放器从候选真实起点开始预览，避免把起点前的动态画面误认为候选内容。
5. 支持人工指定删除区间：按钮设置 In/Out，快捷键 `I` / `O` 分别设置起点和终点。
6. 多次方向检测和相似定位结果持续保留，不再因为重新查找而清除上一批结果；每次查找保存独立的批次、锚点和参数信息。
7. 支持按来源、查找批次、时长、时间范围、方向检测音频条件和“仅已勾选”统一筛选历史结果，筛选同时作用于候选列表和时间轴。
8. 支持单选、多选、全选当前筛选结果；人工区间、相似定位和方向检测结果统一管理，并可批量“删除所选区间”或“设为不删除”。
9. 使用统一自定义进度时间轴替代原生进度条：支持点击/拖动定位、鼠标画面预览，并按不同颜色标记方向检测、相似定位、人工区间和待删除区间。
10. 提供向左/向右区域跳转：整条时间轴统一分成“区间区域”和“间隔区域”，包括第一个区间之前的最左侧区域与最后一个区间之后的最右侧区域。左永远先到当前区域起点、再到左邻区域起点；右永远先到当前区域终点、再到右邻区域终点。间隔开始取前一区间结束后的下一帧，间隔结束取后一区间开始前的上一帧；没有任何可见区间时整条时间轴就是一个区域，左到 0、右到视频末尾。
11. 提供向左/向右单帧步进按钮，按媒体实际 FPS 精确定位 In/Out 边界。
12. 实时计算全局已选区间的删除总时长和预计输出时长；筛选不会改变已经隐藏的删除计划。
13. 使用 FFmpeg Smart Copy / Smart Render 优先导出，必要时自动回退精确重编码。
14. 导出过程展示进度，源文件永不修改。

## 核心原则

- FFmpeg 负责媒体分析和视频输出，Renderer 不直接执行系统命令。
- Electron Main Process 统一封装 ffmpeg / ffprobe 调用。
- 用户删除的是“时间区间”，源视频始终只读。
- 检测与删除解耦：自动检测只生成候选，最终删除由用户确认。
- 长视频导出优先采用 Keyframe-aware Smart Copy；非关键帧切点采用局部 GOP Smart Render；不满足安全条件时自动回退全量精确重编码。
